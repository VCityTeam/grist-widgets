# Grist Widgets

There are many [custom Grist widgets](https://support.getgrist.com/widget-custom/) without licenses or from unreliable sources. This repo exists purely to provide stable, FOSS, widgets for use within VCity projects.

## Widgets

1. [Markdown+Mermaid](/markdown-mermaid) : A simple visualizer widget for [Markdown](https://www.markdownguide.org/) with [Mermaid](https://mermaid.ai/) support
   - Widget URL to use in Grist: `https://vcityteam.github.io/grist-widgets/markdown-mermaid`
2. [Nominatim Geocoder](/nominatim-geocoder) : Geocodes an address column using [Nominatim](https://nominatim.org/), writing back latitude, longitude, OSM type, OSM ID, administration level, address rank, and the matched feature's boundary as GeoJSON
   - Widget URL to use in Grist: `https://vcityteam.github.io/grist-widgets/nominatim-geocoder`
